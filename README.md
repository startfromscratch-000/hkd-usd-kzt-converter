# HKD · USD · KZT

Mobile converter for Hong Kong dollars, US dollars, and Kazakhstani tenge. Type an amount in any field and the other two follow the latest mid-market rates.

https://startfromscratch-000.github.io/hkd-usd-kzt-converter/

## Install on iPhone

Open the site in Safari, tap Share, then tap Add to Home Screen.

## Install on Android

Open the site in Chrome, open the Chrome menu, then tap Add to Home screen.
